# 던컨2 클랜 관리 사이트 사용설명서

사이트 주소: https://clanmanager-lucky.vercel.app

이 설명서는 기존 운좋은 클랜 관리 사이트에서 이름을 변경한 **던컨2** 사이트를 기준으로 작성되었습니다.

## 1. 로그인과 회원가입

### 기존 클랜원 로그인

1. 사이트에 접속합니다.
2. 닉네임과 비밀번호를 입력합니다.
3. `로그인`을 누릅니다.
4. 초기 비밀번호로 로그인한 경우 안내에 따라 비밀번호를 변경합니다.

### 자동 로그인

- 로그인 화면에서 자동 로그인 옵션을 선택하면 같은 기기에서 다시 접속할 때 자동으로 로그인됩니다.
- 공용 PC에서는 자동 로그인을 선택하지 마세요.
- 로그아웃하면 해당 기기의 자동 로그인 정보도 해제됩니다.

### 신규 회원가입

1. 로그인 화면에서 회원가입을 선택합니다.
2. 닉네임과 필요한 정보를 입력합니다.
3. 회원가입 신청 후 운영자의 승인을 기다립니다.
4. 운영자가 승인하면 로그인할 수 있습니다.

## 2. 사용자 권한

### 클랜원

- 로비와 개인 정보 조회
- 참여율과 보스 참여내역 조회
- 분배금, 장부, 금고분배현황 등 허용된 메뉴 조회
- 마이페이지에서 본인 정보와 비밀번호 관리
- 본인이 배운 컬렉템 스킬 완료 처리

### 사진사

- 클랜원 기능 사용
- 출석체크와 보스 참여 기록 등록

### 운영자

- 모든 조회 기능 사용
- 회원가입 승인·거절
- 클랜원 정보와 권한 관리
- 출석 및 보스 기록 관리
- 금고 아이템 지급 관리
- 클랜·클래스 목록 관리
- 각종 운영 설정 관리

## 3. 주요 메뉴

### 로비

- 사이트의 주요 현황을 한눈에 확인합니다.
- 공식 공지 최신 소식을 확인합니다.
- 운영자는 보스타임 미참여 현황과 관리용 알림을 확인할 수 있습니다.

### 내 정보 확인

- 본인의 닉네임, 클래스, 전투력과 참여 현황을 확인합니다.

### 참여율 조회

- 등록된 출석·보스 참여 기록을 기준으로 참여율을 확인합니다.
- 기본적으로 전투력순 또는 설정된 정렬 기준으로 표시됩니다.
- 기간과 활동 종류에 따라 결과를 조회할 수 있습니다.

### 보스 참여내역 조회

- 날짜별 보스 참여 기록을 확인합니다.
- 본인이 참여한 기록과 최근 기록을 확인할 수 있습니다.

### 분배금 조회

- 회차별 분배금과 개인 지급 내역을 확인합니다.

### 통장현황·장부 조회

- 클랜 자금 입출금과 장부 내역을 확인합니다.
- 수정 가능한 범위는 권한에 따라 달라집니다.

### 금고분배현황

- 영무 1티어, 영방 1티어, 초상화, 유언 지급 현황을 확인합니다.
- 운영자는 지급 대상과 수량을 선택하고 지급을 확정할 수 있습니다.
- 지급 후에는 누가, 누구에게, 무엇을, 몇 개 지급했는지 기록이 남습니다.
- 아이템별 아이콘을 누르면 해당 아이템의 지급 이력을 확인할 수 있습니다.

### 아이템입찰

- 등록된 아이템과 입찰 관련 정보를 확인하고 권한에 따라 처리합니다.

### 컬렉템 지급현황

- 클랜원별 컬렉템과 스킬 완료 상태를 확인합니다.
- 직업, 스킬명, 상태 등으로 필터링할 수 있습니다.
- 기본 명단은 전투력순으로 확인할 수 있습니다.

### 마이페이지

- 본인의 닉네임, 길드, 클래스와 비밀번호를 관리합니다.
- 미완료 컬렉템에서 본인이 배운 항목을 완료로 체크할 수 있습니다.
- 완료 처리한 항목은 미완료 목록에서 사라집니다.
- 잘못 완료한 항목을 되돌려야 하는 경우 운영진에게 문의하세요.

## 4. 출석체크 방법

출석체크는 운영자와 사진사가 사용할 수 있습니다.

### 참여자 입력 방식

1. 출석체크 메뉴를 엽니다.
2. `참여자 입력`을 선택합니다.
3. 참여한 클랜원의 닉네임을 입력합니다.
4. 날짜와 활동을 확인한 뒤 저장합니다.

입력한 사람만 참여자로 저장됩니다.

### 미참여자 입력 방식

1. `미참여자 입력`을 선택합니다.
2. 참여하지 않은 클랜원의 닉네임을 입력합니다.
3. 저장하면 활성 클랜원 중 입력한 미참여자를 제외한 나머지가 참여자로 저장됩니다.

주의 사항:

- 활성 클랜원 명단을 기준으로 계산합니다.
- `미피`는 항상 참여 및 미참여 계산 대상에서 제외됩니다.
- 저장 전 날짜, 활동명과 입력 방식을 다시 확인하세요.

## 5. 운영자용 클랜원전투관리

관리자 설정에서 `클랜원전투관리`를 선택합니다.

표에는 다음 항목이 표시됩니다.

- 닉네임
- 길드
- 클래스
- 신화여부: `쌍신화 / 외신화 / X`
- 에노크여부: `O / X`
- 전투력
- 권한
- 정보수정
- 비밀번호
- 권한변경
- 삭제

### 신화·에노크 정보 변경

- 신화여부 또는 에노크여부 선택창에서 값을 고르면 즉시 저장됩니다.
- 기존 클랜원은 처음에 `신화 X`, `에노크 X`로 표시됩니다.

### 클랜원 정보 수정

1. 대상 클랜원의 `수정`을 누릅니다.
2. 닉네임, 길드, 클래스, 전투력 등 필요한 정보를 변경합니다.
3. `저장`을 누릅니다.

### 비밀번호 초기화

1. 대상 클랜원의 열쇠 버튼을 누릅니다.
2. 새 비밀번호를 확인하거나 입력합니다.
3. 초기화를 확정합니다.
4. 새 비밀번호는 해당 클랜원에게 별도로 전달합니다.

### 권한 변경

- `클랜원 / 사진사 / 운영자` 중 하나를 선택합니다.
- 본인의 운영자 권한과 마지막 운영자 계정은 실수로 해제할 수 없게 보호됩니다.

### 클랜원 삭제

- 삭제는 명단에서 비활성 처리하는 방식입니다.
- 과거 출석·분배 기록은 보존됩니다.
- 본인 계정과 마지막 운영자 계정은 삭제할 수 없습니다.

## 6. 클랜·클래스 목록 관리

관리자 설정에서 `기타 설정`을 선택합니다.

### 클랜 추가

1. 클랜명과 표시 색상을 입력합니다.
2. `추가`를 누릅니다.
3. 추가된 클랜은 클랜원 미리 등록, 개별 정보 수정, 전체수정과 클랜 필터에 표시됩니다.

### 클랜 수정·삭제

- 클랜명과 색상을 변경할 수 있습니다.
- 삭제 버튼을 누르면 확인창이 표시됩니다.
- 목록에는 최소 1개의 클랜이 남아 있어야 합니다.
- 목록에서 클랜을 삭제해도 기존 클랜원에게 저장된 길드 정보는 자동 삭제되지 않습니다.

### 클래스 관리

- 클랜과 같은 방법으로 클래스를 추가·수정·삭제할 수 있습니다.
- 변경된 클래스는 클랜원 관리와 마이페이지 선택창에 반영됩니다.

## 7. 금고 아이템 지급 방법

1. `금고분배현황`을 엽니다.
2. 지급할 아이템을 선택합니다.
3. `- / 숫자 직접 입력 / +`로 지급 수량을 정합니다.
4. 명단에서 지급 대상을 체크합니다.
5. `전체 선택 > 인원 적용`을 누릅니다.
6. 적용된 인원 목록을 확인합니다.
7. 잘못 포함된 사람은 닉네임 옆 `×`로 제거합니다.
8. `지급 확정`을 눌러 저장합니다.

지급 후 반드시 지급 수량, 지급 대상과 지급 로그를 확인하세요.

## 8. 문제가 생겼을 때 확인할 사항

### 새로고침 후 로그아웃됨

- 자동 로그인을 선택하지 않았거나 자동 로그인 쿠키가 만료되었을 수 있습니다.
- 다시 로그인해 주세요.

### 수정 버튼이 보이지 않음

- 해당 기능은 운영자 또는 사진사 전용일 수 있습니다.
- 본인의 권한을 운영진에게 확인하세요.

### 새 클랜이나 클래스가 선택창에 보이지 않음

- 페이지를 한 번 새로고침합니다.
- 기타 설정에 해당 항목이 정상적으로 남아 있는지 확인합니다.

### 모바일에서 표가 잘림

- 표 영역을 좌우로 밀어서 확인할 수 있습니다.
- 브라우저 확대 비율을 기본값으로 맞춰 주세요.

### 지급·출석 기록을 잘못 저장함

- 추가 입력으로 덮어쓰지 말고 먼저 운영진에게 알립니다.
- 기록의 날짜, 활동명, 대상자를 함께 전달하면 확인이 빠릅니다.

## 9. 운영 시 주의사항

- 클랜원 삭제·권한 변경·지급 확정 전 대상 닉네임을 다시 확인하세요.
- 공용 기기에서는 자동 로그인을 사용하지 말고 사용 후 반드시 로그아웃하세요.
- 비밀번호를 다른 사람에게 공개하지 마세요.
- 출석과 지급 기록은 통계에 반영되므로 테스트 목적으로 저장하지 마세요.
- 이상한 데이터가 보이면 임의로 여러 번 수정하지 말고 운영진에게 문의하세요.
