# 운좋은 알림봇 사용설명서

## 1. 주요 기능

운좋은 알림봇은 Discord에서 보스 일정, 운세, 무작위 추첨, 클랜 사이트와 공지를 확인하고 게임 화면 숫자 감시 상태를 확인하는 봇입니다.

매일 다음 시간에 웹훅 자동 알림도 전송합니다.

| 알림 시각(한국시간) | 일정 |
| --- | --- |
| 11:55 | 12시 월드보스 5분 전 |
| 12:55 | 13시 게헨나 5분 전 |
| 19:55 | 20시 월드보스 5분 전 |
| 20:55 | 21시 게헨나 5분 전 |

자동 일정 알림은 Railway 서버에서 실행되므로 개인 컴퓨터나 Discord 방송을 켜둘 필요가 없습니다.

## 2. 슬래시 명령어

Discord 채팅 입력창에 `/`를 입력한 뒤 아래 명령어를 선택합니다.

모든 명령어 응답은 명령어를 실행한 채널에 공개되어 채널 구성원 모두가 볼 수 있습니다.

### `/보스일정`

매일 반복되는 12:00 월드보스, 13:00 게헨나, 20:00 월드보스, 21:00 게헨나 일정을 표시합니다.

### `/다음보스`

현재 한국시간을 기준으로 가장 가까운 다음 보스와 남은 시간을 표시합니다.

### `/감시상태`

게임 화면 숫자 감시 프로그램이 마지막으로 전송한 변경 기록을 표시합니다. 아직 감시 프로그램이 실행된 적이 없다면 기록이 없다는 안내가 표시됩니다.

### `/알림테스트`

봇이 온라인이고 슬래시 명령어 응답이 정상인지 확인합니다. 응답은 채널의 모든 사용자에게 표시됩니다.

### `/운세`

외부 한국어 운세 API에서 오늘의 문구를 가져옵니다. 외부 API가 일시적으로 실패하면 봇에 내장된 기본 운세를 대신 표시합니다.

### `/뽑기`

`숫자`에는 뽑을 사람 수를, `인원목록`에는 이름을 쉼표로 구분해 입력합니다. 최대 50명까지 입력할 수 있으며 중복 이름은 허용하지 않습니다.

예: `/뽑기 숫자:2 인원목록:철수,영희,민수,지수`

### `/사이트`

운좋은 클랜 사이트 주소를 표시합니다.

### `/도움말`

현재 사용할 수 있는 명령어와 간단한 사용법을 표시합니다.

### `/공지`

현재 저장된 클랜 공지를 채널에 표시합니다.

### `/공지등록`

서버 관리자가 `내용`에 공지를 입력해 저장합니다. 예: `/공지등록 내용:이번 주 토요일 20시 집결`

## 3. 게임 화면 숫자 변경 알림

숫자 변경 알림은 Discord 방송을 읽는 기능이 아닙니다. 게임이 실행되는 Windows PC에서 별도의 화면 감시 프로그램을 실행해야 합니다.

1. 게임에서 `3/200` 형식의 숫자 화면을 띄웁니다.
2. `pc-watcher/coordinate_picker.py`를 실행해 숫자 영역의 좌표를 확인합니다.
3. `pc-watcher/config.json`의 감시 영역 좌표를 수정합니다.
4. 다음 명령으로 감시 프로그램을 실행합니다.

```powershell
cd pc-watcher
python watcher.py
```

숫자의 분자가 `3/200`에서 `4/200`처럼 바뀌면 PC 프로그램이 Railway 백엔드로 결과를 보내고, 데이터베이스 저장 후 Discord 웹훅 알림을 전송합니다.

게임 창 위치, 해상도 또는 UI 크기가 바뀌면 캡처 좌표를 다시 맞춰야 합니다.

## 4. 명령어가 안 보일 때

1. Discord를 완전히 종료했다가 다시 실행합니다.
2. 채팅 입력창에 `/`를 입력하고 `운좋은 알림봇`을 검색합니다.
3. 해당 채널에서 봇에게 `채널 보기`, `메시지 보내기`, `빗금 명령어 사용` 권한이 있는지 확인합니다.
4. Railway의 `clanmanager-lucky` 서비스가 `Active`인지 확인합니다.

명령어는 운좋은 서버에 직접 등록되므로 정상 배포 후 보통 바로 표시됩니다.

## 5. 보안 주의사항

- Discord 봇 토큰은 Railway의 `DISCORD_BOT_TOKEN` 환경변수에만 저장합니다.
- 봇 토큰, 웹훅 URL, `WATCH_API_KEY`를 채팅이나 GitHub에 올리지 않습니다.
- 토큰이 공개되었다면 Discord Developer Portal에서 즉시 토큰을 초기화하고 Railway 값을 교체합니다.
- 숫자 감시는 화면 읽기와 알림만 수행하며 게임을 자동 조작하지 않습니다.

## 6. 배포 구성

- 봇 및 백엔드: Railway `clanmanager-lucky`
- 데이터베이스: Railway MySQL
- 프론트엔드: Vercel `clanmanager-lucky`
- 봇 명령어: JDA 기반 Discord 길드 명령어
- 예약 및 숫자 변경 알림: Discord Webhook
